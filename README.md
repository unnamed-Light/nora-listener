Персональный академический ИИ-ассистент для студентов, преподавателей и исследователей. Приложение обеспечивает сверхбыструю расшифровку аудио- и видеозаписей лекций, локальную спектральную диаризацию речи (разделение голосов преподавателя и аудитории), автоматическое формирование структурированных конспектов с поддержкой математических формул KaTeX и организацию библиотеки учебных материалов.

---

## Ключевые возможности

- **Высокоскоростная транскрибация речи**:
  Интеграция с моделями Whisper Large v3 (1.55 млрд параметров) и Whisper Large v3 Turbo через сверхбыстрый облачный LPU-движок Groq. Полуторачасовая лекция расшифровывается за 15-30 секунд с высокой точностью терминологии и знаков препинания.

- **Нативная локальная предобработка аудио (DSP)**:
  Встроенный аудиопроцессинг на Rust выполняет фильтрацию верхних частот (High-Pass фильтр 80 Гц) для устранения низкочастотного гула аудитории и нормализацию пиковой громкости перед отправкой на распознавание.

- **Спектральная диаризация спикеров по тону голоса (F0)**:
  Алгоритм спектрального анализа на Rust в реальном времени определяет фундаментальную частоту основного тона голоса и автоматически размечает реплики: преподаватель и вопросы студентов.

- **Интеллектуальный конспект с KaTeX**:
  Кнопка «Сделать умный конспект» запускает модель Llama 3.3 70B Versatile, которая структурирует аудиозапись в готовый учебный материал: ключевые тезисы, определения терминов, перечни понятий и математические формулы, визуализируемые библиотекой KaTeX. Предусмотрен режим «Показывать цитаты преподавателя» для привязки тезисов к первоисточнику.

- **Режим «Два окна (Сплит)»**:
  Параллельное отображение полного стенографического транскрипта слева и умного конспекта справа с возможностью плавного изменения пропорций окон мышью.

- **Организация библиотеки и Drag-and-Drop**:
  Полноценная файловая структура: вложенные папки, свободное перемещение файлов лекций курсором мыши (внутрь папок, между папками и в корень), авто-раскрытие папок при удержании курсора, 4 режима сортировки (по дате и названию) и сквозной поиск по текстам и конспектам (Ctrl+F).

- **Экспорт в популярные форматы**:
  Экспорт материалов в один клик в форматы DOCX (Microsoft Word), PDF, TXT и Markdown.

## Безопасность и конфиденциальность

- **Ключ API хранится только у вас**: Ваш ключ Groq API сохраняется исключительно в локальном хранилище вашего устройства и никогда не передается сторонним серверам.
- **Локальная обработка**: Вся фильтрация сигналов, спектральный анализ диаризации и управление файловой библиотекой выполняются на 100% локально на вашем компьютере движком Rust.

## Быстрый старт

### Вариант 1: Использование готового приложения (для пользователей)

1. Перейдите в раздел **Releases** репозитория.
2. Скачайте архив `NoraListener_v1.0.0_Portable.zip` (портативная версия, не требует установки) или установщик `.msi` / `setup.exe`.
3. Запустите `Nora Listener.exe`.
4. В окне «Параметры» (иконка шестеренки в верхнем правом углу) укажите ваш бесплатный ключ Groq API.

### Вариант 2: Сборка из исходного кода (для разработчиков)

#### Требования
- **Node.js**: версия 20 LTS или новее
- **Rust toolchain**: версия stable (`rustup default stable`)
- **C++ Build Tools**: Visual Studio C++ Build Tools (компоненты MSVC для Windows)

#### Пошаговые команды

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/nora-listener.git
   cd nora-listener
   ```

2. Установите зависимости JavaScript:
   ```bash
   npm install
   ```

3. Запустите приложение в режиме разработки:
   ```bash
   npm run tauri:dev
   ```

4. Запустите тесты бэкенда Rust:
   ```bash
   npm run test:rs
   ```

5. Соберите оптимизированный релизный дистрибутив:
   ```bash
   npm run tauri:build
   ```
   Готовые исполняемые файлы и установщики будут созданы в папке `src-tauri/target/release/`.

## Настройка бесплатного API-ключа Groq

1. Перейдите на официальный портал [Groq Console](https://console.groq.com/keys).
2. Зарегистрируйтесь или авторизуйтесь через учетную запись Google/GitHub.
3. Нажмите кнопку **Create API Key** и скопируйте созданный ключ (начинается с `gsk_...`).
4. В приложении Nora Listener откройте окно «Параметры» (кнопка в правом верхнем углу окна) и вставьте ключ в соответствующее поле.

## Горячие клавиши

- `Ctrl + F` — фокус на строке поиска по библиотеке лекций.
- `Enter` — в полях создания/переименования папок подтверждает ввод.
- `Escape` — закрытие диалоговых окон настроек и руководства.
